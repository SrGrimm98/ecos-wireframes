# ECOS · Wireframes

Wireframes de baja fidelidad de **ECOS**, la plataforma para artistas independientes: el lado del artista (Artist OS) y el lado del fan, con Semiffusa como ejemplo.

**Ver en línea:** https://srgrimm98.github.io/ecos-wireframes/

- Todos los números, nombres de venues, montos y fechas son **datos de ejemplo**.
- Cada pantalla tiene un botón para cambiar entre modo claro y oscuro.
- Las pantallas del fan se pueden configurar desde "Configurar ejemplo" o por URL, por ejemplo:
  `fan-perfil.html?artista=Semiffusa&acento=%23E5262C`

Son HTML y CSS estáticos, sin dependencias.
